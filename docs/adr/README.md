# Architecture Decision Records

One file per decision, numbered `NNNN-short-slug.md`. ADRs capture **architectural /
operational** choices with concrete consequences and actions (e.g. the CI + branch-protection
contract in `0001`). The **design and experimental-protocol** decisions — the pre-registration
lock and future consequential forks — live in the decision record `../../PHASE0_LOCK_DECISIONS.md`
(D1–D5+), and the frozen world in `../simulator_spec.md`. New ADRs are added as the platform grows
(Phase 7 formalizes the set).
